# Calibration and validation plan

## 1. Calibration principles

Sensors in a poultry environment must be calibrated and located correctly. Calibration is not a one-time step only; it requires periodic validation because dirt, humidity and sensor drift change over time.

## 2. Required calibration tasks

### Temperature and humidity
- verify against a reference device in the same enclosure
- check offset and drift after installation
- confirm sensor placement avoids direct sunlight and local heat sources

### CO₂
- verify zero and span conditions if the sensor supports it
- ensure the probe is placed where airflow is representative, not directly in a dead air pocket
- avoid placing the sensor in the immediate path of the exhaust if it would artificially bias readings

### NH₃
- confirm calibration method per the manufacturer
- validate that the sensor is placed where ammonia accumulates, but not within a direct splash or moisture path
- consider reference gas testing or a known-safe verification method if the sensor is critical to safety logic

## 3. Field validation

- log readings over at least several daily cycles before final threshold tuning
- compare day/night conditions and winter/summer operation
- validate that the ventilation response matches the actual air quality trend

## 4. Maintenance record

Maintain a log of:

- sensor replacement dates
- calibration dates
- offset corrections
- observed drift and anomalies
- service actions

## 5. Final note

Until the final sensor layout and ventilation geometry are confirmed, calibration values remain preliminary and must be treated as field-tuning inputs rather than final production values.
