# Checklisty do wydruku

Dokumenty są przygotowane do wydruku w formacie A4. Przed użyciem uzupełnij dane instalacji i wersję konfiguracji. Zaznaczaj `OK`, `NOK` albo `N/D`; przy `NOK` opisz problem i nie przechodź do kolejnego etapu, jeśli dotyczy bezpieczeństwa.

## Dokumenty

- [01 — Checklista montażowa](./01-checklista-montazu.md)
- [02 — Checklista uruchomieniowa](./02-checklista-uruchomieniowa.md)

Checklisty są dokumentacją pomocniczą. Nie zastępują projektu elektrycznego, pomiarów ochronnych, instrukcji producentów ani oceny osoby odpowiedzialnej za instalację. Prace przy napięciu sieciowym wykonuje osoba z wymaganymi kwalifikacjami.
